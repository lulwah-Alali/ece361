# ECE 361 - Homework 3

## Description
This homework implements four pointer functions in C:
- swap_float: Swaps two float values.
- minmax: Finds the minimum and maximum values.
- find_above: Finds the first value greater than a threshold.
- reverse: Reverses an array in place.

## Build
Run:
make

## Tests
Run:
make test

## Clean
Run:
make clean
